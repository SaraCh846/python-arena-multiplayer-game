# Python Arena - Multiplayer Network Game

A two-player networked snake game developed using Python, Pygame, TCP sockets, and JSON.
Developed as a three-person team project.

## My Contributions
- Worked mainly on gameplay and server-side behavior, including player movement, collisions, health changes, and end-game conditions.
- Helped connect and debug the client-server communication so multiple players could interact correctly in real time.
- Spent a large part of the project on integration and testing, making sure the networking, interface, and game logic worked together as one system.

## Technologies
- Python
- Pygame
- TCP Sockets
- JSON
